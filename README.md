# sheridan-dc-systems-2026

Maya Python tools, scripts, and supporting materials developed for Sheridan College's Digital Creature Systems course in 2026.

This repository is used to manage and version course-related code, develop tools between classes, and maintain access to lesson preparation materials across work locations.

## Repository Contents

### Maya Python Tools

Scripts and modules developed to support character rigging exercises and Digital Creature Systems lessons, including joint setup, control creation, local axis display, and rigging utilities.

### Lesson Materials

Supporting scripts, examples, and code developed for classroom demonstrations and practical exercises.

### Technical Environment
- **Software:** Autodesk Maya
- **Language:** Python
- **Course:** Digital Creature Systems — Sheridan College
- **Year:** 2026

Scripts may depend on Maya's Python environment and the `maya.cmds` module. They are intended to be run within Maya unless otherwise specified.

### Development Notes

This is an evolving working repository. Code may be updated, reorganized, or extended as lessons are prepared and course content develops.
